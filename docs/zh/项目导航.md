## 🚀 快速启动

### Windows 用户（推荐）

**后端：**
```bash
双击运行: start-backend.bat
```

**前端：**
```bash
双击运行: start-frontend.bat
```

### 命令行用户

**后端：**
```bash
cd backend
pip install -r requirements.txt
uvicorn app.main:app --reload
```

**前端：**
```bash
cd frontend
npm install
npm run dev
```

## 🔍 如何查找代码

### 查找功能实现

**问：如何实现流式问答？**
→ 查看 `backend/app/services/rag_service.py` 中的 `ask_question` 方法

**问：如何上传文档？**
→ 查看 `backend/app/api/knowledge_base.py` 中的 `upload_document` 函数

**问：如何展示引用来源？**
→ 查看 `frontend/src/views/Chat.vue` 中的 sources 部分

### 查找配置

**问：如何修改 LLM 模型？**
→ 编辑 `backend/.env` 中的 `LLM_MODEL`

**问：如何修改 API 地址？**
→ 编辑 `frontend/vite.config.ts` 中的 proxy 配置

**问：如何修改数据库连接？**
→ 编辑 `backend/.env` 中的 `DATABASE_URL`

## 💡 快速定位问题

### 后端问题

**启动失败：**
1. 检查 `backend/.env` 配置
2. 查看终端错误信息
3. 参考 `QUICKSTART.md` 排查步骤

**API 报错：**
1. 访问 http://localhost:8000/docs 查看 API 文档
2. 运行 `python scripts/test_api.py` 测试
3. 检查日志输出

### 前端问题

**页面无法访问：**
1. 确认后端已启动
2. 检查 `frontend/vite.config.ts` 代理配置
3. 查看浏览器控制台错误

**功能异常：**
1. 打开浏览器开发者工具
2. 查看 Network 标签页请求
3. 检查 Console 错误信息
