## 🚀 下一步操作

### 1. 配置环境（首次运行必须）

#### 方式 A：使用 Docker（推荐）

```bash
# 1. 安装 Docker Desktop
# 下载：https://www.docker.com/products/docker-desktop/

# 2. 编辑后端环境变量
# 编辑 backend/.env 文件，填入阿里百炼 API Key:
DASHSCOPE_API_KEY=你的API Key

# 3. 启动所有服务
docker-compose up -d

# 4. 初始化数据库（首次运行）
docker exec -it rag_backend python /app/../scripts/init_db.py
```

#### 方式 B：本地开发

```bash
# 1. 安装 PostgreSQL 和 Redis
# - PostgreSQL: https://www.postgresql.org/download/
# - Redis: https://github.com/tporadowski/redis/releases

# 2. 配置后端环境变量
# 编辑 backend/.env 文件

# 3. 初始化数据库
python scripts/init_db.py

# 4. 运行爬虫（生成测试数据）
cd crawler
pip install -r requirements.txt
playwright install chromium
python pdd_crawler.py

# 5. 导入向量库
cd ..
python scripts/import_products.py
```

### 2. 启动服务

#### 后端：
```bash
# 方式 1：使用启动脚本（Windows）
双击 start-backend.bat

# 方式 2：命令行
cd backend
pip install -r requirements.txt
uvicorn app.main:app --reload
```

#### 前端：
```bash
# 方式 1：使用启动脚本（Windows）
双击 start-frontend.bat

# 方式 2：命令行
cd frontend
npm install
npm run dev
```

### 3. 访问应用

- **前端界面**：http://localhost:5173
- **后端 API 文档**：http://localhost:8000/docs
- **默认管理员**：admin / 123456

## 💡 常见问题

### Q: 后端启动失败？
A: 检查 PostgreSQL 和 Redis 是否启动，.env 配置是否正确

### Q: 前端无法连接后端？
A: 确保后端已启动在 http://localhost:8000

### Q: 问答没有结果？
A: 检查向量库是否有数据：`python scripts/import_products.py`

### Q: 阿里百炼 API 报错？
A: 检查 API Key 是否正确，账户余额是否充足
