# 完整环境安装脚本

## 一、安装 PostgreSQL

1. 下载 PostgreSQL
   - 访问: https://www.postgresql.org/download/windows/
   - 下载最新版本 (15 或更高)

2. 安装步骤
   - 双击安装文件
   - 记住设置的密码（建议设置为：postgres）
   - 端口使用默认：5432
   - 完成安装

3. 创建数据库
打开命令提示符：
```cmd
psql -U postgres

# 输入以下 SQL 命令：
CREATE DATABASE rag_db;
CREATE USER raguser WITH PASSWORD 'ragpass123';
GRANT ALL PRIVILEGES ON DATABASE rag_db TO raguser;
\q
```

## 二、安装 Redis

1. 下载 Redis for Windows
   - 访问: https://github.com/tporadowski/redis/releases
   - 下载最新的 .zip 文件

2. 安装步骤
   - 解压到 C:\Redis
   - 双击运行 redis-server.exe

3. 验证 Redis
打开新的命令提示符：
```cmd
redis-cli ping
# 应该返回 PONG
```

## 三、安装 Python 依赖

```cmd
cd D:\code\projects\longChain_RAG\backend
pip install -r requirements.txt
```

如果下载慢，使用国内镜像：
```cmd
pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
```

## 四、安装前端依赖

```cmd
cd D:\code\projects\longChain_RAG\frontend
npm install
```

如果下载慢，先设置国内镜像：
```cmd
npm config set registry https://registry.npmmirror.com
npm install
```

## 五、初始化数据库

```cmd
cd D:\code\projects\longChain_RAG
python scripts\init_db.py
```

## 六、（可选）安装爬虫依赖

```cmd
cd crawler
pip install -r requirements.txt
playwright install chromium
```

## 完成！

现在可以启动项目了：
- 后端: 双击 start-backend.bat
- 前端: 双击 start-frontend.bat
